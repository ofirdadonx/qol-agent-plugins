# Alps road trip (fictional sample)

A two-country family trip with flexible dates, a child, and gluten-free restrictions on two of three travelers (the union is gluten-free). Only the outbound flight is booked, so `validate_trip.py` reports stay and transfer **gaps** and a **BOOK FIRST** list.

Places and names are **invented**. Built from [`../sample-answers-alps.json`](../sample-answers-alps.json).
